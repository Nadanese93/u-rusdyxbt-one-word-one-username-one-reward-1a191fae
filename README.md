Entry for the Make.fun bounty **One Word, One Username, One Reward**
(`u-rusdyxbt-one-word-one-username-one-reward-1a191fae`).

The program writes our own make.fun username — one word, nothing else —
to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

```
noble-otter-26
```

Run it with:

```sh
python3 main.py
```

Python 3 standard library only. No network, deterministic, byte-identical
across runs.
